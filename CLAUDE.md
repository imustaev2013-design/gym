# Зал — PWA для учёта тренировок

Личное приложение для iPhone 13 (390×844). Vite + React + TypeScript, Dexie (IndexedDB), без бэкенда.
Минимализм: чёрный/белый/серый, SF-шрифт, портрет, русский интерфейс.

## Запуск
Node лежит локально в `.tools/` (не в git):
```
export PATH="$PWD/.tools/node-v22.23.5-darwin-arm64/bin:$PATH"
npm run dev -- --host     # открыть с iPhone в той же Wi-Fi
npm run build
```

## Структура
- `plan.json` — план (цикл A1→B1→A2→B2, отдых после B1/B2). Правится руками.
  Шаги: штанга 2.5, гантели 1 (вес за одну гантель), блок 5, трицепс с канатом 2, подтягивания (доп. вес) 2.5.
- `src/logic.ts` — выбор тренировки «сегодня», предзаполнение, строка «В прошлый раз».
- `src/db.ts` — Dexie-схема (workouts, bodyWeights, photos, settings), `storage.persist()`.
- `src/components/Today.tsx` — стартовый экран, галочки, сохранение при каждом действии.
- `src/stats.ts` — 1RM (Эпли+Бжицки), история упражнения, форматирование.
- `src/components/History.tsx`, `Progress.tsx`, `LineChart.tsx` (SVG), `Page.tsx` — разделы из меню.
- `standards.json` + `src/standards.ts` — пороги силы (ПРИБЛИЗИТЕЛЬНЫЕ, сверить со strengthlevel.com), процентили, профиль (пол/возраст в db.settings).
- `src/components/Achievements.tsx`, `Settings.tsx` — достижения, настройки (пол, возраст, тема, размер).
- Рекорд на раз (`db.records`, вводится вручную) отделён от расчётного 1RM; `RecordNudge.tsx` раз в 30 дней предлагает внести рекорд (можно отложить на 7 дней).
- Пропуск тренировки автоматический: нет галочек и нет «Завершить» → день считается пропущенным (`missedDays`), тренировка не теряется, а переносится на следующий день (цикл идёт только по выполненным).
- Вес тела (`BodyWeight.tsx`), фото (`Photos.tsx`, сжатие в `backup.ts`), бэкап (`Backup.tsx`, JSON со всеми данными и фото), напоминания (`Nudges.tsx`: бэкап 14 дн., фото 21 дн., рекорд 30 дн.; показывается одно).
- PWA: `vite-plugin-pwa` (vite.config.ts), `src/pwa.ts` (тихое обновление в первые 5 с, иначе строка «Обновить»), иконки/заставки в `public/`, деплой `.github/workflows/deploy.yml` (VITE_BASE=/<repo>/).
- Дизайн-референс главного экрана: `design/main-screen-design.html` (экран тренировки сделан по нему), иконка: `design/app-icon.svg` (PNG в `public/` сделаны из неё).
- Навигация — стек слоёв (`App.tsx`), назад кнопкой или свайпом от левого края: `src/useSwipeBack.ts`, обёртка `components/Page.tsx`.
- `src/App.tsx` — шапка, переключатель дня, экран отдыха, меню-шит.

## Принципы
- История общая по `exId`, прогрессия — отдельно на пару (день, упражнение).
- Тренировка создаётся в БД при первом действии, не при открытии.
